# TontooUiProtocol

The `tontoo_ui` protocol is a custom Wayland protocol that lets client
applications send declarative widget trees for server-side rendering. The
compositor owns the full rendering pipeline -- clients never upload buffers
or draw pixels.

## Protocol Definition

The protocol is generated by `wayland-scanner` in `src/protocol.rs` from
`../protocol/tontoo_ui.xml`:

```rust
pub mod tontoo_ui {
    pub use wayland_server;
    pub extern crate wayland_backend;

    pub mod __interfaces {
        wayland_scanner::generate_interfaces!("../protocol/tontoo_ui.xml");
    }
    use self::__interfaces::*;

    wayland_scanner::generate_server_code!("../protocol/tontoo_ui.xml");
}
```

The XML file is not checked into the repository and must be provided at build
time.

## Global

The `tontoo_ui_manager` global is registered in
`TontooCompositor::new` with version 1.

## TontooUiState

```rust
#[derive(Debug, Default)]
pub struct TontooUiState {
    pub surfaces: HashMap<ObjectId, TontooUiSurfaceState>,
}
```

Top-level state holding all active surfaces, keyed by the `tontoo_ui_surface`
object id.

### Methods

| Method | Description |
|---|---|
| `insert_surface(id)` | Registers a new surface, returns a mutable ref |
| `remove_surface(id)` | Removes a surface, returns the removed state |
| `get_surface(id)` | Immutable lookup |
| `get_surface_mut(id)` | Mutable lookup |
| `find_by_wl_surface(wl_surface)` | Finds state by the associated `wl_surface` |
| `find_by_wl_surface_mut(wl_surface)` | Mutable variant |
| `surfaces()` | Iterator over all surface states |
| `surfaces_mut()` | Mutable iterator |

## TontooUiSurfaceState

```rust
pub struct TontooUiSurfaceState {
    pub title: String,
    pub width: i32,
    pub height: i32,
    pub glass: Option<GlassConfig>,
    pub color_scheme: TontooColorScheme,
    pub widget_data: Vec<u8>,
    pub parsed_tree: Vec<FlatWidget>,
    pub wl_surface_id: ObjectId,
    pub mapped: bool,
    pub surface_resource: Option<TontooUiSurface>,
    pub last_hovered_node: Option<usize>,
}
```

Defaults: width 800, height 600, color scheme dark, no glass effect.

## TontooColorScheme

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u32)]
pub enum TontooColorScheme {
    Dark = 0,
    Light = 1,
}
```

### TontooColorScheme::from_wire

```rust
pub fn from_wire(value: u32) -> Option<Self>
```

Converts a wire `uint` to a scheme. Unknown values return `None`.

## GlassConfig

```rust
pub struct GlassConfig {
    pub milkiness: f32,
    pub alpha: f32,
    pub sigma: f32,
}
```

Controls the frosted-glass effect: tint intensity (`milkiness`), background
alpha (`alpha`), and Gaussian blur radius (`sigma`). Defaults: 0.5 / 0.6 /
20.0.

## Requests

| Request | Description |
|---|---|
| `get_tontoo_ui_surface` | Creates a new surface (manager) |
| `pong` | Client responded to a ping |
| `set_title` | Sets the surface title |
| `set_size` | Sets the surface size (clamped to min 1x1) |
| `set_glass` | Sets glass effect; all-zero disables it |
| `update_widget_tree` | Sends a serialized widget tree |
| `set_color_scheme` | Sets the surface color scheme |
| `request_close` | Client asks to close (currently only logged) |
| `request_minimize` | Client asks to minimize (currently only logged) |
| `request_maximize` | Client asks to maximize (currently only logged) |

## Events

| Event | Description |
|---|---|
| `widget_clicked` | A widget was clicked, sends node id |
| `widget_hovered` | Pointer hovered a widget, sends node id |
| `key_event` | Keyboard event forwarded to the surface |
| `configure` | Configures the surface size |
| `close` | Requests the client to close |

## Wire Format

Widget trees are serialized in a compact binary format defined in
